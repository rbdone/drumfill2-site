The Library

19 demo songs to start with, plus everything you make.

  1. On Play, tap the library key; the tab bar then reaches Library, Setlists, Kits and Settings.
  2. Filter by genre chips or search. Tap a song's name to open it on Play.
  3. The ••• key on a song: Play, Edit song, Edit as text, Duplicate, Add to favorites, Add to setlist, Share, Export audio, Delete (with undo).

Song Builder

Genre + form → a complete, playable song.

  1. Library → Build a song.
  2. Pick a genre and a form (Pop, Rock, AABA, 12-bar blues, Folk, Build/drop, Jam), and a tempo, then BUILD SONG.
  3. For any section: 🎲 rerolls it; ⇄ opens the pattern browser already filtered to the song's genre, feel and tempo.
  4. REROLL ALL starts over; SAVE & PLAY keeps it and opens it on Play.

At the bottom of Song Builder, Build by beatboxing makes a song from your voice: see the Beatbox guides.

Quick Chart

Type a song the way musicians write charts on a napkin.

  1. Library → Type a chart (or a song's ••• → Edit as text).
  2. Type the tempo, meter, genre and sections, e.g. @120 4/4 rock I2 V8 C8 V8 C8 O2. Section letters: I intro, V/A verse, P/B pre-chorus, C chorus, Br bridge, S solo, Bk breakdown, O outro; the number is bars.
  3. Extras: (V8 C8)x2 repeats, [2/4] an odd bar, Br8:3/4 another meter, C8@+10 or Br8@half tempo changes, C8{stop 8.1} cues, V8' a variation, O2~ ring-out, "vocals in" a cue note. The shortcut keys type them for you.
  4. Mistakes are underlined with a plain-English fix; tap it to apply.
  5. SAVE & PLAY. Grooves are picked for the genre, so it plays right away.

Commas, new lines and lowercase are fine, so you can paste a chart from a message.

Song Editor

Every detail of a song, in four tabs.

  1. A song's ••• → Edit song.
  2. Sections: each section's groove, fills, end fill, intensity, cue note, meter and tempo. Edit the Chorus once and every Chorus changes. ▶ auditions it.
  3. Arrangement: drag steps to reorder, − / + bars, tap a step to duplicate, remove, add a note or cues, or insert odd bars.
  4. Ending: fixed, ring-out or ritard. Text: the whole song as a Quick Chart.
  5. Tap SAVE; ▶ opens it on Play.

Cues: stops, hits and tacets

The band stop on beat 3 of the last chorus bar? Write it in.

  1. Song Editor → Arrangement → tap a step, then Add cue.
  2. Choose the bar and beat, then Stop (drums cut), Hit (kick + crash, groove continues), Hit + Stop, Resume (with a fill, sticks or nothing) or Tacet (no drums for some bars while time keeps running).
  3. ADD CUE, then SAVE. On Play the block shows a small marker and “STOP on 1” flashes one bar early.

Pattern Browser

300 original patterns: 200 grooves, 50 fills, 25 intros, 25 endings.

  1. Library → Patterns.
  2. Filter by kind, genre, feel, meter and “fits” the current tempo; the sliders key adds tempo, complexity, energy and sort.
  3. Tap a card to hear it loop at your tempo with your kit; tap again to stop. Long-press for a favourite. Use “Similar” to find neighbours.

Pattern Editor

Make your own groove on a step grid.

  1. Patterns → +.
  2. Choose 16, 32 or triplet steps. Tap a cell to add a hit, tap again to remove it; long-press for velocity (ghost, normal, accent). + Row adds instruments.
  3. Tap-record lets you play it in instead.
  4. ▶ loops it; ✓ saves it. Use it in any song section.

Share songs, import MIDI, export audio

Get the whole band on the same chart.

  1. A song's ••• → Share sends a .pdsong file through any app (email, chat, Drive, Nearby Share). A setlist's share key sends a .pdset with all its songs.
  2. Whoever opens it sees a preview and taps Import. Missing kits fall back to Studio. Set your name in Settings → Your name so they see who made it.
  3. Library's ↑ key imports a General MIDI drum file or a shared song.
  4. ••• → Export audio renders the song to a WAV file.
